# Security

Quokka Bot holds logins and reads untrusted pages and mail, so security reports get priority.

Report a vulnerability privately through GitHub: **Security → Report a vulnerability** on this repository. Do not
open a public issue. Include what an attacker can reach, the steps to reproduce, and the version or commit.

You get an acknowledgement within three working days. Fixes ship as a release with a security advisory that credits
the reporter unless you ask otherwise.
