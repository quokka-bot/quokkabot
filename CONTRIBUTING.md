# Contributing

Thanks for helping. A few things keep reviews quick:

- **Agree on the problem first.** For anything bigger than a small fix, open a Discussion or an issue and describe
  the problem before writing code.
- **One problem per PR**, with the verification you ran (see the PR template). `pnpm check` must pass.
- **Security issues** go through [SECURITY.md](SECURITY.md), never a public issue.
- **Agents welcome.** If an AI agent wrote the change, say which model and tool; you are still the one who answers
  for it. [AGENTS.md](AGENTS.md) has the layout, commands and rules.
